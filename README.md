# Sprint Project: Video Game Sales Analysis

In this project, I used basic Python to clean up messy text and make sense of raw data. I calculated key metrics like average global sales and compared how games performed across different regions. I also built loops and conditionals to filter games by release year, publisher, and top sellers. Finally, I used dictionaries and custom functions to group the data, finding things like total sales by genre and the number of games each publisher released. 

Dataset Source: Provided as precode in the TripleTen Basic Python sprint project.
